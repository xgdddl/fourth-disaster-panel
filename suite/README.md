# 第四天灾 · 最终整合在线版 V1.3.19

[下载唯一导入文件](https://github.com/xgdddl/fourth-disaster-panel/releases/download/v1.3.19/fourth-disaster-online-v1.3.19.json)

一个酒馆助手脚本自动加载统一状态栏、沉浸阅读与创意工坊，无需分别导入三个入口。

导入后只启用这一份整合入口，停用原来单独的统一面板、沉浸阅读与创意工坊脚本；不用删除它们。MVU、ZOD与已有世界书继续保留。更新时原位替换既有整合脚本的名称与代码，保留其实际脚本ID；工坊草稿、安装记录、立绘和聊天数据不迁移。

T 阅读设置统一提供正文字号、字体和背景选择，进入工坊或档案前关闭设置浮层。标题、角色摘要、正文两侧与档案材质随六种高清场景联动；配套枫叶、细雨、雪屑、余烬与海面光点。沿用原图与原URL，动效仅当前界面播放，支持减少动态效果。工坊在两种模式下共享原生内容皮肤，按实际栏宽排版，填写与数值参考默认折叠。开场白与检定正则保持原文件；工坊填写说明引用开场白既有装备与技能规则。

此在线入口固定加载v1.3.19。本轮包含针对工坊接管与角色识别的回归检查，实际界面检查结果另见交付开发记录；未做实体手机性能测量。
