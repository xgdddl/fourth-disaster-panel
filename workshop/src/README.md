# 第四天灾创意工坊 V0.1.3 · 本地美化版

面向第四天灾 3.2 的内容扩展工坊。它是统一面板的可选配套脚本，工坊入口位于主导航控制台之前，不新增常驻悬浮窗，不替换统一面板或注册 ZOD。

## 使用

1. 保持原统一面板只启用一份。将交付目录的 `第四天灾创意工坊-V0.1.3.json` 导入酒馆助手脚本库，再手动启用；同类工坊只启用新版。当前本机已原位更新现有全局工坊，勿再重复导入。
2. 打开第四天灾单人角色聊天和统一面板，点击“工坊”。
3. 在“已安装”创建本角色专用扩展世界书。主世界书和原有附加世界书均保留。扩展书绑定在角色级别，同一角色的其他聊天也可能读取启用的扩展条目。
4. 浏览在线目录，或“查看离线示例”/导入 JSON，先预览，再安装。新增内容默认停用，启用由你选择。
5. 已手动指定后台所读世界书时，把新扩展书加入控制台的世界书选择范围；使用默认绑定范围时会自动纳入。停用条目不会进入现有后台候选。
6. 在创作台使用普通表单编辑单条作品；完整 JSON 支持多条合集。保存草稿、导出与离线安装无需登录，线上发布使用 Discord 身份。

V0.1.2增加上传教程、武器与玩家内容分类，登录弹窗未出现时提供直接授权链接。保留页面接管：进入工坊时隐藏并禁止操作旧状态栏／后台内容区，显示工坊路径；退出恢复原页。旧页高层级不再盖住工坊，旧的推进／续跑按钮和角色资源不混进工坊。原登录、草稿、世界书与存档不重置，不调用生成API。

V0.1.3只调整本地工坊外观与展示结构：暗金铜线、烟青底、暖白正文与楷体标题；电脑左侧完整栏目，手机固定窄栏显示发现／安装／创作／教程／发布／连接，六项均可见；作品卡、详情、空目录、教程、连接页统一材质；表单分作品档案与世界书条目，作品工具折叠，保存／发布位于内容末尾，不用浮动栏遮挡输入。没有新增图片、网络字体或持续动画。

本机沿用原工坊脚本ID和启用状态。原登录、草稿、作品安装与恢复规则保留；本次未发布或撤回作品，未修改扩展世界书，未部署公开工坊服务或GitHub在线入口。下载包仍默认停用。

## 更新与恢复

- `packageId + entryId` 跟踪同一内容，更新保留宿主 UID。新版本号由服务器确定，编辑以 baseVersion 检查并发。
- 默认更新保留本地改写，以及作者新版移除的旧条目。“更新并覆盖本地修改”是另一个显式操作，只处理该作品。
- 卸载未修改条目；本地改写过的条目会保留并解除工坊来源标记。
- 每个聊天保留最近一次工坊操作的扩展书快照，支持导出。恢复前检查整个扩展书是否仍等于操作后的结果；发生后续变化会停止自动恢复。
- 写入后立即持久保存并回读。错误不报告成功；可能已经部分写入时保留恢复记录供核对，不自动把失败写成已回退。
- 草稿、登录和恢复记录保存在当前浏览器 IndexedDB，不随脚本导出。不完整 JSON 文本也会保存。

## 支持范围

奇遇、副本、武器、玩家、NPC、生物、组织和地区设定。格式是 `fourth-disaster-workshop/1`，目标 `fourth-disaster/3.2`，不直接导入异录作品包。每包 1–100 条，单条正文最多 100 KiB，规范化作品包最多 1 MiB。

NPC 正文使用 `NPC-姓名`，生物使用 `生物-名称`；势力、阵营、地区按当前后台分类约定命名。安装提供候选素材，不能等同于已发生剧情、已接任务、已接触人物或获得奖励。地图标记、自动依赖安装、核心变量规则、ZOD/脚本安装、评论点赞、管理员界面均不在首版范围。

## 源码

- `core.js`：作品格式、字段归一、内容边界、更新与卸载计划。
- `manager.js`：独立扩展书、宿主作用域、备份、写入、回读、恢复。
- `app.js`、`style.css`：统一面板入口、目录、编辑台、离线模式、登录与发布。
- `service/`：独立托管源码。D1 保存作者、会话摘要、作品索引和完整历史版本；迁移在 drizzle/。
- `build.cjs`：构建可导入脚本、示例作品和校验文件，同时同步服务端格式规则与公开脚本下载。
- `test.cjs`：格式/更新/宿主事务检查，及真实 SQLite 上的共享 API 与受控 Discord 路由检查。
- `qa-server.cjs`：仅本机的隔离 UI 验证宿主，模拟 API，不属于正式服务，也不是酒馆实玩验收。

构建：`node work/fourth_disaster_workshop/build.cjs`。
逻辑检查：`node --test work/fourth_disaster_workshop/test.cjs`。
服务：进入 service/，`npm ci`、`npm run build`。Sites 项目身份保存于 `.openai/hosting.json`，不要新建重复项目；使用 Sites 工作流同步源码与发布。

服务端环境变量：`DISCORD_CLIENT_ID`、`DISCORD_CLIENT_SECRET`、`PUBLIC_URL`。Client Secret 只保存在托管项目秘密配置；源码、脚本、交付包均不包含。Discord redirect 固定为 `PUBLIC_URL/api/discord/callback`，仅请求 identify。当前 proof 是客户端会话关联摘要，不称为 OAuth PKCE。

## V0.1.3 补充

工坊支持武器、装备、饰品、特殊物品、玩家等分类。装备对齐现有ZOD的防具字段；特殊物品按实际用途映射消耗品、材料或杂物，不改正式变量枚举。页面内确认替代原生窗口；已撤回作品仅在作者页保留历史。
