# 第四天灾 · 酒馆统一面板

将角色状态、世界演化、人物、势力、公会、排行榜、玩家社区与地图合并为一个酒馆辅助面板。启动默认收起，悬浮入口可拖动。

## 安装

1. 下载 [第四天灾在线入口 V1.2.4](https://github.com/xgdddl/fourth-disaster-panel/raw/refs/tags/v1.2.4/%E7%AC%AC%E5%9B%9B%E5%A4%A9%E7%81%BE-%E5%9C%A8%E7%BA%BF%E5%8A%A0%E8%BD%BD%E7%89%88.json)。
2. 在酒馆助手的全局脚本库导入该 JSON，然后启用。
3. 停用原来的离线统一面板、独立状态栏及独立论坛，避免重复运行。其他助手不受影响。

需要 SillyTavern、酒馆助手，以及与面板相匹配的本地变量/世界书。它不是独立角色卡；安装脚本不会自动获得作者的聊天、世界书或个人配置。

## 如何工作

酒馆助手保存短入口 → 从固定版本读取 dist/index.js → 图片从同版本 assets/ 加载。完整程序仍在酒馆本地浏览器运行；GitHub/CDN 不替我们运行世界或调用 AI。API 密钥、连接方案、聊天进度都留在酒馆。浏览静态资源仍会产生普通网络访问。

地图保留 67 个名称和必要几何数据，不内嵌世界书原文。地点简介从当前选中的本地世界书读取；有资料才展示，读取失败显示提示，不用发布文件里的故事冒充当前世界书。

## 版本与调用

仓库为 [xgdddl/fourth-disaster-panel](https://github.com/xgdddl/fourth-disaster-panel)。项目方已于 2026-10-15 确认可公开发布修改版，来源和第三方权利见 [说明](THIRD_PARTY_NOTICES.md)。

当前固定 v1.2.4，不使用 main/latest 静默更新。以后每次发布用新标签，旧版本继续保留用于回退。安装不代表必须开启推演；是否调用、独立模块、重试及格式修复，由控制台设置决定。重试/修复会增加 API 请求。推演请求仍会发给你自行配置的 API 服务商，不经过本仓库作者的服务器。

当前地图分为一张刻绘自然地形和28幅透明地标资源；67处建筑或自然标记与地点标记共用坐标。自然峡谷、隘口等不用城堡冒充。程序、地形、地标、场景均在同一固定版本目录下读取，不能只上传 index.js 而漏掉 assets。完整地点内容从本地世界书和正式档案读取，刷新地点资料不调用AI。控制台的隐藏与停用偏好留在本地，启动默认收起，悬浮入口可拖动。

地址格式依据 [jsDelivr 官方说明](https://github.com/jsdelivr/jsdelivr#github)。GitHub Pages 不是必需，也不是后台推演服务器。

## 安装、失败与回退

- 停用离线版再启用在线入口，不要同时开启两份。旧副本由维护者在酒馆助手原生脚本库清理，面板不包含管理、备份或删除其他脚本的功能。
- 网络加载失败会显示明确提示，可手动重试。不能联网时，停用在线入口、启用离线版，不会清空存档或切换 API。
- 坐标版本仍为 2（0～1000）。不要回退到只支持旧坐标的版本，更不能把坐标重复乘十。旧聊天迁移仍需明确预览、下载备份后确认。
- manifest.json 保存构建时文件大小、SHA-256 与发布准备状态，不是实时在线状态。静态资源的可访问性也不代表你的模型 API 可用。

## 发布边界

本仓库只发布：dist/、assets/、manifest.json、package.json、在线入口、README 和第三方说明。不以本仓库名义为第三方代码重新授予统一开源许可。

不发布：世界书 JSON、角色卡、聊天、API 方案、头像/立绘私有文件、截图测试报告、坐标迁移备份、全部旧版本和整个工作区。完整离线交付包含本地世界书时也不能整包上传。

本轮 UI 只改变呈现、地图交互和设置页局部刷新，不修改正文、战斗计算、资产或世界推演调用方案。真实手机还须在移动设备上补测双指手势；浏览器窄屏通过不等于所有手机硬件均流畅。
