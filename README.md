# 第四天灾 · 统一状态栏

把眼前的冒险和世界背后的故事，放进同一个面板。既能查看角色状态，也能观察一个持续运转的第四天灾世界。

- **角色与冒险**：生命魔力、装备行囊、技能、任务和已接触的角色资料；支持手动学习、遗忘技能。
- **变量维护**：不用后台推演，也能查看基础MVU状态。控制台支持手动修复、报错自动修复、每轮变量核对三种互斥模式，默认手动；检查通过直接写回变量，不重写故事。手动每点一次额外1次，报错模式正常回合0次，每轮核对模式每个有效完成回合额外1次。
- **世界演化**：经济、政治、环境与技术的变化，持续发展的事件和各方势力动向。
- **玩家生态**：玩家活动、公会、排行榜与论坛社区，让冒险之外也有故事发生。
- **交互地图**：探索大陆、查找地点，点开查看本地世界书和已接触记录。
- **幕后联动**：世界、NPC与玩家互相影响，发展结果可通过线索与后果带入正文。

可按轮次或游戏时间推进，自选参与内容与独立调用，支持失败重试和格式修复。深浅主题、可拖动入口与手机布局均已整合。
